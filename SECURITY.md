# Security and privacy

This is a personal-use research and engineering portfolio. The public repository
contains application source, tests, documentation, and synthetic dashboard fixtures.
It does not include brokerage credentials, local configuration, account databases,
private experiment records, or production logs.

Keep runtime configuration and data in ignored local files. Never paste credentials,
account identifiers, callback responses, or database contents into an issue, pull
request, screenshot, or example. Test data must be explicitly synthetic.

For a security concern, use this repository's **Security → Report a vulnerability**
option. Do not include sensitive account information in a public issue.

The [safety contract](docs/SAFETY.md) documents authentication, order confirmation,
risk controls, auditability, and the boundary between paper and live workflows.
